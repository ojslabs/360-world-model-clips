# 360° World Model Clips

Create 360° video highlights with H3 world models. Choose a moment from a YouTube
video, generate a moving viewpoint around the selected freeze-frame, and return
to the original action.

Each highlight combines eight seconds of original footage, a six-second H3
sequence, and four seconds of resumed action. Background audio accompanies the
generated sequence; the F1 demo slows its own source sound down and speeds it back
up as the action resumes.

- Search and preview videos before importing.
- Choose the exact moment with frame-by-frame controls.
- Follow progress and see completed highlights appear automatically.
- Export individual highlights or combine them into a reel.

H3 generation runs at 1080p. Optional 4K exports preserve the original source
detail and upscale the generated sequence. Generated motion and framing can vary,
so review the result before sharing.
